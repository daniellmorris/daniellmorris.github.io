What Declarack provides¶

Capability Where to learn
Template-based connection setup Add an integration
Search, sorting, filters, exports and bulk actions Table tools
Reusable forms, reviewed changes and tracked plans Workflow reference
Scheduled checks and persisted history Checks tutorial
Two real Swarms, monitoring and SSH tunnels Multi-environment lab

Declarack is a configurable administration framework with Docker and Swarm as its most complete integrations. It does not claim full Portainer parity, notification delivery, distributed scheduling or SSO/RBAC. See current coverage for the exact boundaries.
