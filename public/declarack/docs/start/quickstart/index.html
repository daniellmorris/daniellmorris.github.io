Get started with Declarack¶

Choose a real Docker installation, a sample-data preview, or the API tutorial. All commands below run from the repository root.

Prerequisites¶

For Docker management, install Docker with Compose and ensure the engine is running. For the source-based API tutorial, use Python 3.12+ and Node 22.12+ instead. The examples use Linux containers, including on Docker Desktop.

git clone https://github.com/daniellmorris/declarack.git
cd declarack

The repository currently requires access to the private GitHub project. Use your normal authorized Git credentials; do not put a token in a copied clone URL.

Run against your Docker engine¶

export DECLARACK_PASSWORD='choose-a-strong-local-password'
docker compose up -d --build

Open http://127.0.0.1:8080, sign in as admin, and use the password you exported. The default bootstrap detects a standalone engine or a local Swarm manager. You should see inventory from that engine, not sample data.

The base Compose file mounts the Docker socket and persists application data in declarack-data. Socket access gives administrative control of the engine. Keep this installation on loopback or behind your normal authenticated HTTPS access.

Enable guided integration setup¶

The Add integration wizard saves new files, so it needs folder-backed settings. Follow the configuration workflow to mount a writable folder. Then open Targets → Add integration, choose a template, review the generated YAML, test the connection, save, and activate configuration.

A target is a connection. An environment is an optional group of targets; adding a connection does not require a new environment. Read the terminology.

Explore sample data instead¶

docker build -t declarack .
docker run --rm -e DECLARACK_MODE=demo -p 127.0.0.1:8080:8080 declarack

Stop the other port-8080 installation first, or publish this preview on a different host port. Demo mode uses sample inventory and temporary data; it does not prove that real Docker mutations, SSH connections or container cloning work.

Learn the framework without Docker¶

The first API interface tutorial starts a real local HTTP server and connects Declarack to it. You will inspect data, perform a harmless training action and use dynamic dropdowns before building a dashboard across targets.

Stop and return later¶

docker compose stop

Start again with docker compose up -d. Keep the data volume and configuration folder. Do not remove volumes as a routine shutdown step. See deployment and persistence before moving an installation.
